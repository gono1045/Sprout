## 1. プロジェクト概要

### 1.1 目的

Sproutは、タスク管理とゲーミフィケーション（植物の育成）を組み合わせたWebアプリケーションです。

- 個人学習としての開発（Spring Boot / Java の実践）
- 自分自身が実際に使いたいと思えるプロダクト

### 1.2 ターゲットユーザー

- 個人でタスク管理をしたいエンジニア・学習者
- 作業へのモチベーション維持に困っているユーザー

## 3. 非機能要件

| 項目 | 要件 |
|---|---|
| 認証・認可 | Spring Security。ログイン済みユーザーのみアクセス可。他ユーザーのデータへのアクセス禁止 |
| データ分離 | タスク・タグはユーザーIDで分離（user_id による行レベル制御） |
| パスワード | BCrypt でハッシュ化して保存 |
| レスポンシブ | Tailwind CSS 4.x を使用。基本はデスクトップ想定 |
| ダークモード | CSS変数で対応。ヘッダーのトグルで切替 |
| ブラウザ対応 | モダンブラウザ（Chrome・Safari・Edge）を対象 |

## 4. 技術スタック

| 区分 | 技術 |
|---|---|
| バックエンド | Java 17 / Spring Boot 3.5.8 |
| ORM | JPA（基本CRUD） + MyBatis（複雑なJOINクエリ） |
| フロントエンド | Thymeleaf（SSR） + Tailwind CSS 4.x |
| JavaScript | バニラJS（jQuery・Day.js・flatpickr・Lucide） |
| DB | PostgreSQL（port: 5432 / DB名: sprout） |
| ビルド | Maven（バックエンド）/ npm（CSSビルド） |
| 認証 | Spring Security + UserDetailsService実装 |

## 5. データモデル（主要テーブル）

| テーブル | 概要 |
|---|---|
| `sprout_user` | ユーザー情報 |
| `sprout_item` | タスク（title / status_cd / priority_cd / deadline / detail） |
| `sprout_tag_list` | タグ（tagName / tagColor / exp / lv） |
| `sprout_item_tag` | タスク ⇔ タグの中間テーブル |
| `sprout_work_log` | 工数記録（itemId / startedAt / endedAt / durationMin / satisfaction / memo / expTotal） |
| `m_code` | コードマスタ（ステータス・優先度等） |
| `sprout_password_reset_token` | パスワードリセットトークン |
