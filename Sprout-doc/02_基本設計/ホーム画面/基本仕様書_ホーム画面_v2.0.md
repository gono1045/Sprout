## 1. 画面概要

ログイン後のメイン画面。植物グラフィック（Heroセクション）・ツールバー・タスク一覧テーブルの3ブロックで構成される。タスクの閲覧・登録・編集・削除・複製・工数記録をこの画面から行う。

---

## 2. 画面レイアウト

```
┌─────────────────────────────────────────────┐
│  ヘッダー                                     │
│  [Sprout ロゴ]          [テーマ切替] [ユーザー]│

│  ┌──────────────────┬───────────────────────┐│
│  │ Featured タグ     │ マイガーデン            ││
│  │ [植物画像+EXPリング│ [タグカード横スクロール]││
│  │ タグ名・ステージ]  │                       ││
```

---

## 3. ヘッダー

| 要素 | 内容 |
|---|---|
| ロゴ | 「Sprout」テキスト（Merriweather font）。クリックで `/` にリダイレクト |
| テーマ切替ボタン | ライト/ダークモードを切り替える。CSS変数（`--paper` 等）で全体反映 |
| ユーザーボタン | ログインIDの頭文字1文字を表示する緑丸ボタン |
| ユーザードロップダウン | プロフィール・パスワード変更・アカウント設定・ログアウト |

---

## 4. Heroセクション

### 4.1 Featuredタグ（左ペイン）

| 要素 | 内容 |
|---|---|
| EXPリング | SVGドーナツグラフ。選択タグのEXP進捗を0%→現在値へアニメーション |
| 植物画像 | タグに応じた植物PNG（`/img/plant_default.png` 等）。110px × 110px |
| タグ名 | 選択タグのtagName。未選択時は「タグを選択してください」 |
| ステージ | SproutStageEnumから算出したステージ名 |
| EXP表示 | 「現在EXP / 次レベルEXP」形式 |
| EXPバー | 進捗を示すグリーンのプログレスバー |
| 選択解除ボタン | タグ選択時のみ表示。クリックでFeatured解除 |

### 4.2 マイガーデン（右ペイン）

| 要素 | 内容 |
|---|---|
| タグカード | 各タグを横スクロールのカードで表示 |
| カード内容 | タグ名・レベル・植物画像（小サイズ） |
| タップ動作 | カードをクリックでFeaturedタグに設定 |

---

## 5. ツールバー

| 要素 | 種別 | 動作 |
|---|---|---|
| ＋新規ボタン | ボタン（緑・丸角） | タスク新規登録モーダルを開く（`modalFlg=0`） |
| 完了済みを表示ボタン | トグルボタン | 完了ステータスのタスクの表示/非表示を切替 |
| 検索ボックス | テキスト入力 | タイトルでクライアントサイドフィルタリング（即時反映） |

---

## 6. タスク一覧テーブル

### 6.1 表示カラム

| カラム名 | 内容 | 備考 |
|---|---|---|
| （ステータスアイコン） | アイコン表示 | 未着手/進行中/完了で色分け |
| タイトル | タスクのタイトル | クリックで更新モーダルを開く |
| タグ | 紐づくタグをチップ表示 | タグ色付き |
| ステータス | 未着手/進行中/完了 | code_id='01' マスタから取得 |
| 優先度 | 低/中/高 | code_id='02' マスタから取得 |
| 締切 | YYYY/MM/DD | 期限超過時は赤色表示 |
| 詳細 | 詳細テキストの先頭部分 | |
| 工数 | 合計工数（分） | タイマーモーダルへのリンク |
| （操作） | 複製・削除等のアクション | |

### 6.2 ソート順（固定）

```
1. ステータス昇順：進行中 → 未着手 → 完了
2. 優先度降順：高 → 中 → 低
3. 締切昇順
4. 更新日時降順
```

## 7. アクション

| アクション | HTTPメソッド | エンドポイント | 備考 |
|---|---|---|---|
| 初期表示 | GET | `/` | タスク一覧取得 |
| タスク一覧再取得 | GET | `/task/list` | 非同期（JSON） |
| タスク削除 | POST | `/task/delete` | `?id={id}` |
| タスク複製 | POST | `/task/duplicate` | `?id={id}` |
| モーダル表示 | GET | `/modal/update` | `?modalFlg=0 or 1` |

## 8. 画面遷移

```
ホーム画面（/）
  ├─ [＋新規] → タスク登録モーダル（SC-04）
  ├─ タイトルクリック → タスク更新モーダル（SC-04）
  ├─ 工数ボタン → タイマーモーダル（SC-05）
  └─ ユーザードロップダウン
        ├─ プロフィール（SC-06）
        ├─ パスワード変更（SC-07）
        ├─ アカウント設定（SC-08）
        └─ ログアウト → ログイン画面（SC-01）
```
